Este repositório contém as 4 atividades práticas desenvolvidas para a disciplina de Desenvolvimento Web, explorando diferentes abordagens, bibliotecas e estilizações.

---

## 📁 Estrutura do Projeto

* **`atividade-1/`**  
  Recriação de layout do Figma utilizando apenas **HTML5 e CSS3 puro**. Foco em fundamentos de Flexbox, estrutura semântica e estilização básica (Empresa *NovaCore*).

* **`atividade-2/`**  
  Página desenvolvida com **Bootstrap 5** (Loja de Jogos - *GameVault*). Explora componentes nativos como Navbar, Modal, Carrossel de depoimentos e Accordion FAQ.

* **`atividade-3/`**  
  Landing page construída com **Tailwind CSS** (Estúdio de Tatuagem - *Tinta & Agulha*). Foco no uso de utilitários de layout, grid responsivo e estilo escuro.

* **`atividade-4/`**  
  Atividade de **Vibecoding** (Tema: *Bloodborne*). Contém a documentação completa dos prompts, direcionamento de design e validações do código gerado via GitHub Copilot.

---

## 🚀 Como Executar
Basta clonar o repositório e abrir o arquivo `index.html` de qualquer uma das pastas diretamente no navegador.
